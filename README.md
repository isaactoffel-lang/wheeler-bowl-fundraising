# Wheeler Bowl

**Fundraising operations · Event readiness**

Wheeler Bowl documents how an offer moves from outreach through collection and into an event handoff. The key distinction is between what someone agreed to give and what the event team can actually use.

**Start with the [worked handoff](CASE_STUDY.md#work-a-handoff)** or open the [blank tracker](handoff-template.csv). Both are designed around a next action and a responsible role.

The original project also explored item presentation through an auction interface prototype. It was a local interface concept. [Read the case study](CASE_STUDY.md) · [Publication scope](PUBLICATION.md)

The worked example was prepared with AI assistance and uses an invented item.
