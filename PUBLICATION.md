# Publication scope

This public repository contains qualitative project documentation only.

The original implementation and development history are retained privately. This writeup does not provide a runnable application or establish that a live integration is working.

Public additions must exclude prices, financial figures, numeric results, email addresses, contact details, personal records, credentials, account configuration, and screenshots or documents containing them. Do not copy private source, logs, or history into this repository.

Describe the actual implementation and its limits. Preserve attribution and distinguish reviewed behavior from plans. AI assisted with implementation and documentation; that assistance does not establish verification.
